## Описание

### Модуль дискретной случайной величины
Пользователю предоставляется возможность задать вероятности для четырех исходов из пяти ($p_1 \dots p_4$). Программа автоматически вычисляет вероятность пятого исхода ($p_5 = 1 - \sum_{i=1}^4 p_i$) и осуществляет проверку на отсутствие отрицательных значений. Визуализация результатов представляет собой столбчатую диаграмму относительных частот, над каждым столбцом которой выводится полученное эмпирическое значение.

### Модуль нормального распределения
Позволяет моделировать непрерывную нормальную случайную величину с произвольными параметрами. Пользователь задает требуемое математическое ожидание (mean), дисперсию (variance) и объем выборки. На графике строится эмпирическая гистограмма плотности распределения (разбиение на интервалы происходит автоматически встроенными средствами библиотеки `matplotlib`), поверх которой накладывается теоретическая кривая Гаусса для визуальной оценки совпадения.

### Система статистического вывода
Под графиками в реальном времени формируется текстовый блок с результатами вычислений:
* **Точечные оценки**: рассчитываются выборочное среднее и выборочная дисперсия.
* **Погрешности**: вычисляется процентное отклонение сгенерированных параметров от заданных теоретических.
* **Критерий $\chi^2$**: программа вычисляет наблюдаемую статистику, программно определяет степени свободы (для дискретной $k-1$, для нормальной $k-3$), находит критическое значение и выносит логический вердикт (`true` — гипотеза принята, `false` — отвергнута).

## Вероятностные модели

### Моделирование дискретной СВ
В основе лежит метод обратного преобразования. Единичный интервал $[0, 1]$ разбивается на 5 непересекающихся отрезков, длины которых пропорциональны заданным вероятностям $p_1 \dots p_5$. С помощью базового ГПСЧ генерируется равномерно распределенное число $u \sim U(0, 1)$. Значение случайной величины определяется тем, в какой именно кумулятивный отрезок попало число $u$.

### Моделирование нормальной СВ
Использован алгоритм Бокса-Мюллера. Программа берет пару независимых случайных чисел $u_1, u_2 \in (0, 1]$ и трансформирует их в стандартную нормальную величину $Z \sim N(0, 1)$ по формулам:
$$z_0 = \sqrt{-2 \ln u_1} \cos(2\pi u_2)$$
$$z_1 = \sqrt{-2 \ln u_1} \sin(2\pi u_2)$$
Далее применяется линейное преобразование для приведения стандартной величины к пользовательским параметрам мат. ожидания ($m$) и дисперсии ($\sigma^2$):
$$x = z \cdot \sqrt{\sigma^2} + m$$

### Статистические показатели
В процессе обработки выборки объема $N$ используются следующие формулы:
* **Выборочное среднее:** $\bar{x} = \frac{1}{N} \sum x_i$
* **Выборочная дисперсия:** $S^2 = \frac{1}{N} \sum (x_i - \bar{x})^2$
* **Статистика Пирсона:** $\chi^2 = \sum \frac{(n_i - Np_i)^2}{Np_i}$, где $n_i$ — фактическое количество попаданий в интервал, $Np_i$ — теоретически ожидаемое.
* **Относительная погрешность:** $\delta = \frac{|X_{теор} - X_{эмп}|}{|X_{теор}|} \cdot 100\%$
