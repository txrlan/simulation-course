### Система массового обслуживания M/M/1

Моделирование простейшей системы M/M/1.

### Описание приложения

Приложение предназначено для моделирования работы одноканальной системы массового обслуживания без очереди. Приложение позволяет исследовать поведение СМО при изменении параметров входящего потока и скорости обслуживания, сопоставляя полученные экспериментальные данные с теоретическими положениями теории массового обслуживания.

**Модуль настройки и управления**  
Пользователь может настраивать следующие параметры:
*   **Интенсивность поступления ($\lambda$)** - средняя частота прихода новых запросов в единицу времени.
*   **Интенсивность обслуживания ($\mu$)** - среднее количество запросов, которое прибор способен обработать за единицу времени.
*   **Размер выборки ($N$)** - общее число генерируемых заявок в рамках одного эксперимента.

**Система визуализации и анализа**  
Окно программы разделено на функциональные зоны:
*   **Графический модуль:** справа расположен виджет, отображающий столбчатую диаграмму. Она визуализирует сопоставление эмпирических показателей (голубые столбцы) и теоретических вероятностей (фиолетовые столбцы с прозрачностью). На графике отображаются два ключевых состояния системы: состояние свободного прибора ($P_0$) и занятого прибора, приводящее к отказу ($P_1$).
*   **Блок отчета:** в левой нижней части находится текстовая область, куда выводится лог с рассчитанным коэффициентом загрузки $\rho$, вероятностями состояний, абсолютными отклонениями результатов моделирования от теории, а также теоретической и практической абсолютной пропускной способностью системы ($A$).

### Вероятностная модель

**Генерация потока и обслуживания**  
Процесс функционирования СМО M/M/1/0 представляет собой марковский процесс. Интервалы времени между последовательными поступлениями заявок ($\Delta t_{вх}$) и длительность их обработки прибором ($t_{обсл}$) распределены по экспоненциальному закону с параметрами $\lambda$ и $\mu$ соответственно:
$$f(\Delta t_{вх}) = \lambda e^{-\lambda \Delta t_{вх}}, \quad f(t_{обсл}) = \mu e^{-\mu t_{обсл}}$$

В функции `run_simulation` генерация этих интервалов выполняется с помощью экспоненциального распределения библиотеки `numpy` (`np.random.exponential`). Момент прихода каждой $i$-й заявки рассчитывается как кумулятивная сумма интервалов:
$$t_{прих\_i} = \sum_{k=1}^{i} \Delta t_{вх\_k}$$

**Логика симулятора**  
Программа последовательно итерирует каждую заявку. Если момент прихода текущей заявки больше или равен времени освобождения прибора (`arrival >= system_free_at`), заявка принимается к обслуживанию. Время освобождения прибора обновляется: `system_free_at = arrival + process_time`. Если приход зафиксирован до момента освобождения канала, заявка мгновенно отклоняется, увеличивая счетчик отказов.

**Теоретические расчеты**  
Приведенная интенсивность нагрузки (коэффициент загрузки) определяется как:
$$\rho = \frac{\lambda}{\mu}$$

Теоретические вероятности нахождения системы в свободном и занятом состояниях рассчитываются по формулам Эрланга для одноканальной системы с отказами:
*   Вероятность простоя канала: 
    $$P_0 = \frac{1}{1 + \rho}$$
*   Вероятность отказа: 
    $$P_1 = \frac{\rho}{1 + \rho}$$
*   Абсолютная пропускная способность (среднее число заявок, успешно обслуживаемых в единицу времени):
    $$A = \lambda \cdot P_0$$

Соответствующие эмпирические вероятности рассчитываются как доли успешных и отклоненных заявок от общего числа смоделированных запросов $N$.

### Результаты моделирования

Для оценки адекватности имитационной модели были выбраны следующие параметры по умолчанию:
*   Интенсивность поступления ($\lambda$): **5.0**
*   Интенсивность обслуживания ($\mu$): **6.0**
*   Коэффициент загрузки ($\rho$): **$\approx 0.833$**
*   Теоретические вероятности: $P_0 \approx 0.5455$, $P_1 \approx 0.4545$

### Выводы

1.  **Работоспособность алгоритма:** Результаты имитационного моделирования показывают соответствие теоретическим формулам Эрланга для систем без накопителя. Разработанный алгоритм проверки занятости канала на основе сопоставления моментов времени корректно воспроизводит реальный процесс функционирования простейшей СМО M/M/1/0.
2.  **Анализ пропускной способности:** При выбранном соотношении интенсивностей ($\lambda=5.0$, $\mu=6.0$) СМО теряет около $45.4\%$ входящего потока требований. Отсутствие очереди накладывает жесткие ограничения на эффективность обслуживания при высокой интенсивности входящего потока.
3.  **Сходимость результатов:** С увеличением объема выборки $N$ (числа смоделированных событий) от 100 до 1 000 000 наблюдается уменьшение абсолютной погрешности между эмпирическими вероятностями состояний и их математическими ожиданиями. Начиная с $N=100\,000$, расхождение результатов не превышает десятых долей процента, что согласуется с действием закона больших чисел.
