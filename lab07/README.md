### Марковская модель погоды

**Задание:**  
Смоделировать погоду по дням:

- 1 — ясно  
- 2 — облачно  
- 3 — пасмурно  

Единица времени — **1 день**.  
Задать интенсивности переходов между состояниями.

**Требования:**
1. Выполнить моделирование в «реальном» времени с визуализацией.
2. Провести статистическую обработку результатов.
3. Сравнить эмпирическое распределение с теоретическим стационарным.
4. Сбор статистики и всей необходимой информации в .txt или .csv формат (.csv формат предпочтительней)

## Описание приложения
### Модуль настройки и управления
Программа позволяет моделировать погодные условия на основе теории дискретных цепей Маркова. Пользователю предоставляется интерфейс для ввода вероятностей переходов в виде P-матрицы размерностью $3 \times 3$, где сумма элементов в каждой строке должна строго равняться единице. Ползунок скорости позволяет регулировать задержку отрисовки процесса.

### Визуализация
* Выводится дискретное время симуляции (в днях) и текущее состояние системы.
* График динамики построен в виде ступенчатой функции последних 40 переходов.
* Есть динамическая гистограмма, сравнивающая эмпирическую долю времени с аналитически вычисленным стационарным распределением.

## Вероятностная модель
### Непрерывная цепь Маркова
Математическая модель базируется на множестве состояний $S = \{1, 2, 3\}$ и **матрице интенсивностей переходов** (инфинитезимальной матрице) $Q$:

$$
Q = \begin{pmatrix} 
q_{11} & q_{12} & q_{13} \\ 
q_{21} & q_{22} & q_{23} \\ 
q_{31} & q_{32} & q_{33} 
\end{pmatrix}
$$

где $q_{ij}$ (при $i \neq j$) — интенсивность (скорость) перехода из состояния $i$ в состояние $j$. Диагональные элементы определяются как суммарная интенсивность выхода из состояния с отрицательным знаком: $q_{ii} = -\sum_{j \neq i} q_{ij}$. Таким образом, сумма элементов в каждой строке матрицы всегда равна нулю: $\sum_{j=1}^{3} q_{ij} = 0$.

Время пребывания в каждом состоянии является **непрерывной случайной величиной**, распределенной по экспоненциальному закону с параметром $\lambda_i = -q_{ii}$. Это означает, что переходы происходят не в фиксированные моменты времени, а через случайные интервалы $dt$.

### Стационарное распределение
Теоретическое распределение вероятностей $\pi = (\pi_1, \pi_2, \pi_3)$, отражающее долю времени пребывания системы в каждом из состояний при длительном моделировании ($T \to \infty$), вычисляется из системы линейных алгебраических уравнений:

$$
\begin{cases} 
\pi Q = 0 \\ 
\sum_{i=1}^{3} \pi_i = 1 
\end{cases}
$$

Для нахождения единственного решения одно из уравнений системы $\pi Q = 0$ заменяется условием нормировки (сумма вероятностей равна 1). Программно задача решается методом Гаусса (функция `numpy.linalg.solve`) для модифицированной матрицы $Q^T$.

Задача нахождения стационарного распределения сводится к решению системы линейных алгебраических уравнений (СЛАУ) вида $Q^T\pi^T = 0$. Для получения единственного решения матрица $Q^T$ модифицируется: последнее уравнение заменяется условием нормировки $\sum_{i=1}^{3} \pi_i = 1$, что позволяет найти вектор состояний $\pi$ с помощью численных методов (функция `numpy.linalg.solve`).

## Вывод

- Подтверждена эргодическая теорема для марковских процессов с непрерывным временем. На малых интервалах модельного времени ($T < 50$ дней) наблюдаются значительные флуктуации эмпирических долей из-за случайной природы экспоненциального распределения времени пребывания в состояниях. При увеличении общего времени моделирования ($T \to \infty$) эмпирическое распределение (доля времени, накопленная в `time_spent`) асимптотически сходится к теоретическим значениям стационарного распределения.

- При использовании базовой матрицы интенсивностей наиболее вероятным состоянием является «Пасмурно» (40.0%). Это объясняется тем, что данное состояние обладает низкой интенсивностью выхода ($q_{33} = -0.4$, что дает среднюю длительность пребывания 2.5 дня) при относительно высоких интенсивностях перехода в него из смежных состояний (в частности, $q_{23} = 0.4$ из состояния «Облачно»).
