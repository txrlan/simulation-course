## Первая часть: ДА / НЕТ

### Алгоритм датчика случайного события
Моделирование основано на разбиении отрезка $[0, 1]$ на два участка, длины которых соответствуют вероятностям $p$ и $q$.

**Схема алгоритма:**
1. Получить случайное число $r$ из линейного конгруэнтного генератора.
2. Вычесть из $r$ вероятность $p$.
3. Если результат $\le 0$, то наступило событие «ДА».
4. В противном случае наступило событие «НЕТ».

**Реализация в коде:**
```python
# вычисление вероятности "нет"
current_probs = [prob_yes, 1.0 - prob_yes]

# кубик с вероятностями (индекс 0 - да, 1 - нет)
result_index = roll_dice(current_probs, self.rng)
answer = ["ДА", "НЕТ"][result_index]
```

## Вторая часть: Шар предсказаний

Программа моделирует выбор одного из 8 возможных ответов. События выбора каждого ответа образуют **полную группу попарно несовместных событий**.

### Полная группа событий
Для корректного моделирования должны соблюдаться два условия:
1. **Несовместность**: в результате одного использования шара может выпасть только один ответ.
2. **Полнота**: сумма вероятностей всех 8 ответов должна быть равна 1.

**Список ответов и их вероятностей из кода:**
1. Бесспорно ($p=0.15$)
2. Определённо да ($p=0.10$)
3. Возможно ($p=0.25$)
4. Шансы 50 на 50 ($p=0.10$)
5. Спроси позже ($p=0.10$)
6. Сомнительно ($p=0.15$)
7. Маловероятно ($p=0.05$)
8. Точно нет ($p=0.10$)

*Сумма: $0.15+0.10+0.25+0.10+0.10+0.15+0.05+0.10 = 1.0$*

### Алгоритм выбора события из группы
Для поиска выпавшего события используется метод последовательного вычитания вероятностей из случайного числа. Это позволяет определить, в какой сегмент отрезка $[0, 1]$ попало значение $r$.

**Реализация алгоритма в коде:**
```python
def roll_dice(probs, rng):
    r = rng.get_value() # получаем число [0, 1)
    for i, p in enumerate(probs):
        r -= p # вычитаем вероятность текущего варианта
        if r <= 0: 
            return i # cобытие с индексом i произошло
    return len(probs) - 1 # cтраховка от погрешностей float
```
